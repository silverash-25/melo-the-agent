# Standard Deviation Analysis

## Data Source
The file `data.csv` contains three records with values:
- apple: 10
- banana: 20
- cherry: 15

## Calculation
The sample standard deviation of the values (10, 20, 15) is calculated as follows:

1. Mean (average) = (10 + 20 + 15) / 3 = 15
2. Squared differences from mean:
   - (10 - 15)² = 25
   - (20 - 15)² = 25
   - (15 - 15)² = 0
3. Sum of squared differences = 25 + 25 + 0 = 50
4. Sample variance = 50 / (3 - 1) = 50 / 2 = 25
5. Sample standard deviation = √25 = 5.0

## Result
**The sample standard deviation of the values is 5.0.**

This matches the statistical analysis performed by the data_analyze tool, which reported a standard deviation (std) of 5.0 for the 'value' column.
